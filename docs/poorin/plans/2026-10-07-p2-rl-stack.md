# P2 RL Stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete Marin's in-repo RL stack: the SkyRL integration (`marin.rl`), the post-training
experiments built on it, the RL data reviews, and the three RL libraries Verifyit, Shellbox, and
Taskcompendium.

**Architecture:** Pure deletion, outside-in, so every commit leaves the tree green. `marin.rl` and
`experiments/post_training` import each other, so they go together. Taskcompendium imports
Verifyit, so it goes before Verifyit. Verifyit is the only workspace member of the five, so its
commit also edits the manifests and relocks. No root reaches any of this code
(`tools.reachability --why` prints `unreachable` for all of it).

**Tech Stack:** Python 3.12, `uv`, `tools.prune_check`, `tools.reachability`.

**Spec:** `docs/poorin/specs/2026-10-04-core-prune-design.md`, "Pass 1: deletion order" (row P2) and
"Deleted regardless of reachability"; decision D6 ("Delete Marin's in-repo SkyRL integration") in
`docs/poorin/decisions.md`.

## Global Constraints

- Work on branch `prune/p2-rl-stack`, cut from local `main` at `80406b499`. Do not push.
- Run project commands with `uv run --no-sync`. After `uv lock`, resync with
  `uv sync --locked --all-packages --extra=gpu` and confirm `jax.default_backend()` is `gpu`.
- Every commit runs `uv run --no-sync python -m tools.prune_check --phase P2 --step "<label>"`
  first and commits the metrics row with the change. Lint with `uv run --no-sync python -m
  tools.lint` before the check.
- Stage deletions with `git rm` and the rest by existing path; chain `git add` and `git commit`
  with `&&`.
- Commit titles: `[poorin] ...`, imperative, at most 72 characters, no attribution trailer.
- `config/external/` (the pins for Marin's forked dependencies, MarinSkyRL among them) is left to
  P3, which deletes the whole pin machinery with `marin.external_dependencies`.
