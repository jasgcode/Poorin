# P4 to P7 Strip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Finish Pass 1 of the prune quickly: delete Ducky (P4), remove Iris after salvaging its
compile cache and resource detection (P5a to P5c), trim Finelog to its client and delete what only
Iris kept reachable (P6), and sweep every module no root reaches (P7).

**Architecture:** One branch, `prune/strip`, for all four phases (D73). Each commit runs
`tools.prune_check --fast`: it imports every kept root and trains R1 and R2 twice, and skips ty,
lint, and tests, which a cleanup pass after P7 runs and fixes in bulk. Deletions stay outside-in so
the kept roots import and train at every commit.

**Spec:** `docs/poorin/specs/2026-10-04-core-prune-design.md` ("Pass 1" rows P4 to P7, "P5: Iris
removal", "Spike fixes") and its amendment `2026-10-06-workbench-and-roots-design.md` (Dupekit
stays; P7 also deletes the MoE scaling ladder, the reference scaling suite, Levanter's OpenAI
server, the tutorial sweep, and `marin.evaluation.perplexity_gap`). Decisions D68 (SkyRL hooks
stay), D70 (no lockfile, no sync until P8), D73 (this plan's process).

## Global Constraints

- No `uv lock` or `uv sync` until P8 (D70); manifests are edited by hand, and packages for deleted
  members stay installed until P8 resolves a fresh environment.
- `uv run --no-sync python -m tools.prune_check --fast --phase P<n> --step "<label>"` before each
  commit; commit the metrics row with the change.
- Before deleting a module, search the surviving tree for its dotted name and path as strings.
- The SkyRL hooks (D68) and the runnable roots R1 and R2 must keep working.
- Commit titles `[poorin] ...` or a library scope, no attribution; each body says what the code did
  for Marin and why Poorin does not need it.

## P4: Data services

1. Delete Ducky: `lib/ducky`, its dependency, workspace member, and source in the root
   `pyproject.toml`. Nothing imports it.

## P5a: Salvage

2. Move `iris/jax/compile_cache.py` to `levanter/compile_cache.py`, called from
   `levanter.distributed` at process initialization. Cache directory precedence:
   `TrainerConfig.jax_compilation_cache_dir`, then `JAX_COMPILATION_CACHE_DIR`, then
   `~/.cache/poorin/jax`. Drop the node-local scratch mount and the remote autotune mirror. Add the
   NVRTC builtins preload (GPU backend only; a clear error naming the expected path when the
   library is missing). `prune_check` stops setting `LD_LIBRARY_PATH` and
   `JAX_COMPILATION_CACHE_DIR` once training passes without them.
3. Move `iris/env_resources.py` to `zephyr/resources.py` (cgroup v2, cgroup v1, `/proc`; drop the
   `IRIS_TASK_RESOURCES` branch); `zephyr.shuffle` uses it.

## P5b: Cut edges, one commit per library

4. Fray: delete `iris_backend.py`; `current_client()` returns the explicitly set client, otherwise
   `LocalClient`.
5. Zephyr: remove the Iris context checks in `context`, `coordinator`, `worker`, and `stats`.
6. Levanter: `distributed.py` keeps SLURM and JAX's own cluster detection and loses the Iris
   branch; delete `megascale.py`, `callbacks/_iris_status.py`, and `training_control.py` with its
   uses; `tracker/telemetry.py` and `tracker/finelog_metrics.py` take their run identity from
   Levanter's run ID and `jax.process_index()`, and `TelemetryConfig` takes an explicit Finelog URL
   and raises when it cannot connect.
7. Marin executor: `step_status` and `step_runner` keep only the local worker ID;
   `sweep_coordination` keeps only the single-host path; `marin.training.training` loses the
   env-dict cache code; grug's dispatcher stops importing Iris's priority bands;
   `marin.rollouts.catalog` (Iris telemetry, no producer left) goes.
8. Experiments outside the roots that import Iris are deleted (Harrier TEI embeddings, the grug
   MoE hero, FSDP, pipeline, and recovery launchers that use `iris.jax` or Iris RPC).

## P5c: Delete the library

9. Delete `lib/iris`, its workspace membership, `marin-iris` from every `pyproject.toml`, the
   cluster tests under `tests/cluster/` that need a live Iris cluster, `config/testing` fixtures
   only Iris read, Iris host exclusions, and Iris references in docs and `AGENTS.md`.

## P6: Orphans and Finelog trim

10. Trim `lib/finelog` to its Python client (`client/`, `rpc/`, top-level modules, and their
    tests): delete `rust/`, `deploy/`, `benchmarks/`, `dashboard/`, and its operations docs; depend
    on the published `marin-finelog-server` wheel. Delete code that only Iris kept reachable.

## P7: Unreachable sweep

11. One commit per library, deleting every module no root reaches, with its tests and docs:
    `experiments/` (including the MoE ladder, the reference scaling suite, the tutorial sweep, and
    the 14 Levanter model experiments), `marin` (including `marin.evaluation.perplexity_gap`),
    `levanter` (the 14 model modules, the OpenAI server), `zephyr`, `rigging`, `finestore`,
    `haliax`, `fray`, `dupekit`.

## After P7

Cleanup pass: `uvx ty@0.0.84 check`, `tools.lint --all-files`, `tools.affected_tests --all`; fix
what they report; then a local fast-forward merge into `main`.
